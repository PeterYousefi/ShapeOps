# ShapeOps specification
A local-first modular CAD inference platform. React/TypeScript/Vite + Three.js frontend; FastAPI, OpenCascade (CadQuery), and scikit-learn backend. Six screens share real runtime and registry records. The central workflow selects an original procedural sample or uploads STEP, parses/tessellates actual B-rep faces, executes a trained surface-classification baseline, and maps per-face predictions to a selectable mesh. Production and candidate models must be distinct, reproducible and checksum identified. The baseline predicts surface classes; it does not claim BRepNet manufacturing-feature segmentation. Synthetic analytic solids provide owned training data. No production traffic is simulated. Public administration is read-only; an isolated deterministic failure/recovery test can be executed without release mutation. Azure deployment is not authorized.

Design: graphite/navy shell, restrained turquoise signal, compact sidebar and toolbar, large technical viewport, visible units and data origin, contextual right inspector. Default dark; optional light. Mobile retains all screens, viewport controls, face selection and uploads.
