# Retained geometry screening evidence

Successful sample/upload inference now stores a typed per-request geometry observation in the same SQLite transaction as its request row. Failed requests produce no geometry evidence. IDs/source/model must match the successful request, and pruning removes observations when their request leaves the existing1000-row/seven-day retention window. Existing databases gain an empty observation table; no past geometry is invented or backfilled. GET /api/drift?limit=20 returns up to100 recent validated observations, including after process restart. Invalid saved evidence fails closed.

Each observation compares actual face/edge counts, sorted extents, aspect ratio, edges-per-face, total face area and CAD surface-class fractions with the five cached owned sample geometries. It stores each actual value, reference mean/scale and absolute standardized deviation. Scale is max(population standard deviation,5% of absolute reference mean,1e-6), so zero-variance features have a declared finite comparison floor. Deviation>=3 triggers the explicit screening warning. Reference hash binds ordered actual reference vectors, feature names and method/floor/threshold settings; historical values remain stored rather than being recomputed against changed references. Existing trained IsolationForest OOD score/flag are retained separately and validated against their original threshold.

This is per-input comparison/history, not a calibrated industrial population-drift test. The owned procedural reference, floor and threshold are transparent screening choices, not validated production alert thresholds. No p-values, population shift confidence, industrial calibration or production traffic claims are made. Surface fractions come from real parsed CAD surface classes, not predicted class counts. No raw STEP, mesh positions or face feature vectors are saved in this table. Aggregate extents/areas still describe geometry and require an approved export/privacy policy before cloud telemetry.

Pure tests use explicit fixture geometry and hand-check match/shift/reference identity; API tests generate real inference and verify saved values against its face/extent/OOD fields. Retention tests use isolated SQLite and prove no backfill/orphan retention. UI chart integration, window-level distribution tests, industrial threshold validation, alert routing and cloud durability remain open.
