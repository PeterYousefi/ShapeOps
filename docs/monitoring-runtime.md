# Monitoring runtime verification

The required container CI job now runs scripts/monitoring-smoke.sh after building/scanning shapeops:ci. It starts the existing monitoring Compose profile under the separate shapeops-monitoring-ci project, with loopback-only ports 18000/19090/13000. The override requires Docker Compose 2.24.4 or later for !override. No developer 8000/9090/3000 services or volumes are reused. Cleanup removes only this project's containers and volumes, even on failure, and saves stack logs.

The Python probe waits for actual API/Grafana startup, performs real sample flange inference with comparison, and verifies successful telemetry increased. It loads the file-provisioned dashboard via Grafana and checks every panel query/datasource against the tracked specification. Each expression is then queried through Grafana's provisioned Prometheus proxy and compared with actual retained request totals/latest latency. The Prometheus up series must report the ShapeOps scrape healthy. Empty/multiple/nonfinite series, warnings, missing panels and query mismatches fail closed; bounded polling permits the fifteen-second scrape interval. No mock metric source or vector(1) success substitute is used.

artifacts/monitoring-runtime.json records the real trace ID, Grafana version, query values, verification timestamp and explicit CI-only traffic label. This report and stack logs upload with container-security-evidence. Failed runs may have only logs; absence of runtime evidence is not success. Local workstation has no Docker, so genuine stack execution must be established by exact-head hosted CI before claiming runtime verification. This does not verify browser chart rendering, production authentication, long-term metric durability, alerts or cloud services. The current anonymous Viewer setup remains local-only.

Primary API references reviewed: [Grafana 12.2 datasource API](https://github.com/grafana/grafana/blob/v12.2.0/docs/sources/developers/http_api/data_source.md), [Grafana 12.2 dashboard API](https://github.com/grafana/grafana/blob/v12.2.0/docs/sources/developers/http_api/dashboard.md) and [Prometheus HTTP query API](https://prometheus.io/docs/prometheus/latest/querying/api/). Latest documentation is guidance; the pinned runtime's actual CI result is the compatibility evidence.
